How segregation, low birth weight, unemployment, and violence link to low life expectancy in chicago

Dataset DOI: 10.5061/dryad.sxksn03jf

Description of the data and file structure

The data were collected from the Chicago Health Atlas to understand factors linked to low life expectancy in Chicago.

Files and variables

File: SCRIPT_CNA_MANUSCRIPT_HA_SCHOLAR.R

Description: R script file to be used with CNA R “cna” package (v. 4.0.3, 2025).

File: LIFE_EXPECTANCY_CNA_4.1.26_HAScholar.csv

Description: Variable of social factors coded 1 for present and 0 for absent

Variables

CASENAME: Chicago Community Areas

HIGH_LOW_BIRTH_WEIGHT: Low birthweight rate (% of births), 2018-2022

HIGH_UNEMPLOYMENT: Unemployment rate (%), 2019-2023

HIGH_SHOOTINGS: Non-Fatal Shootings, 2022

HIGH_RESIDENTIAL_SEGREGATION: ICE-BlackNH, calculated from 2022 population data

LOW_LIFE_EXPECTANCY: Life expectancy (years), 2022

LIFE_EXP_VALUES: Life expectancy (years), 2022

Code/software

R/R Studio

CNA R “cna” package (v. 4.0.3, 2025).
